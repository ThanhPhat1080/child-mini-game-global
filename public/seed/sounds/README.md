Default "Feedback sounds". Drop the recorded files here (same names):

- hooray.mp3   correct answer
- ohoh.mp3     wrong answer
- complete.mp3 "You did it" at the end of a game

A family's own upload (Settings > Feedback sounds) wins. A missing file falls back to the built-in synthesized sound.

background-track.mp3 is the default background music (loops on the child screens). It is the only background track: families can neither upload their own nor change the volume.

Spoken lines of the play door (lib/voice.ts; a missing file is silent):

- welcome-0.mp3    /play/sign-in, once when the page opens
- who-are-you.mp3  /play/guest and the picker /play
- hi-prince.mp3    Boy picked in the guest setup
- hi-princess.mp3  Girl picked in the guest setup
- welcome-1.mp3    Welcome (tap to enter) for a guest or visitor
- see-you-later.mp3 the "See you later!" popup (sign-out, guest Leave)
